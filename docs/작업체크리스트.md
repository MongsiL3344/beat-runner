### T2에서 주의할 것
- **SFB 빌드 대상 문제**: SFB는 `UNITY_STANDALONE_WIN`을 `UNITY_EDITOR`보다 먼저 검사한다. 빌드 대상을 Windows로 바꾸면 맥 Editor Play 모드에서도 Windows용 선택창 코드를 써서 실패할 수 있다(추정, 미확인). 빌드 후 대상을 맥으로 되돌릴지, 코드 조건을 고칠지 사용자에게 묻는다.
- 맥 SFB 네이티브 파일은 원본이 Intel 전용이라 arm64+Intel 겸용으로 다시 빌드해 넣었다(`Assets/StandaloneFileBrowser/Plugins/StandaloneFileBrowser.bundle`).

### 알아 둘 것
- mp3는 Unity가 인코더 앞뒤 빈 구간을 자르지 않아 실제보다 조금 길게 읽힌다(2.000초 → 2.115초). 재생과 분석이 같은 데이터를 쓰므로 박 타이밍은 어긋나지 않는다.
- 개발용 설정 파일은 `Temp/noiserun_dev.txt.off`로 꺼 둔 상태다. 쓸 때 이름을 `noiserun_dev.txt`로 바꾼다. 자동 테스트는 이 파일을 잠시 치웠다가 되돌린다(`DevFileGuard`).
- Songs 폴더(맥): `~/Library/Application Support/Mongs/beat-runner/Songs/`에 `테스트 곡 120.wav`가 있다.
- 테스트 음원 변환용 ffmpeg는 컨테이너 `/tmp/ff/`에만 있다. 컨테이너가 재시작되면 다시 받아야 한다.
- SSH heredoc 안에서 `unity` 명령을 여러 개 실행할 때는 각 명령에 `</dev/null`을 붙인다. 안 붙이면 첫 명령이 나머지 heredoc을 입력으로 먹어 버린다.
